# Чтобы начать работу нужно сделать пару вещей:

## Клонируй репозиторий: `git clone git@github.com:Asimov-s-Lawbringer/RBAC.git`

## Переключись на ветку develop: `git checkout develop`

## Создай свою рабочую ветку от develop: `git checkout -b feature/frontend-setup`

## Разворачивай свой стек (React/Vue/Vanilla JS) прямо в этой папке `frontend`.

Вкратце иерархия такая: Main (это Святыня,сюда не пушим пока 100 из 100 не будет работать, т.е эта версия *Идеальная* которую мы представим в Пятницу.)
Далее идет Development,на ней у нас "Рабочая сборка",когда закончим промежуточный этап и сольём наши разработки тут могут вылезти ошибки,это ОК.
Главное: Pull Request в DEVELOPMENT!! Создаем свои ветки дополнительно для разработки отдельных функций и основного рабочего процесса.
