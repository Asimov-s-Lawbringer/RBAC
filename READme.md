# RBAC System (Backend API) 🛡️

Серверная часть комплексной системы контроля доступа на основе ролей (RBAC) с поддержкой древовидной иерархии должностей, автоматическим логированием проверок безопасности и динамической фильтрацией логов.

## 🚀 Быстрый запуск через Docker (DevOps)

Для того чтобы поднять бэкенд и базу данных PostgreSQL одной командой, выполните в корне проекта:

```bash
docker-compose up --build
```

*После этого Docker автоматически скачает зависимости, применит миграции, загрузит стартовые фикстуры и запустит API на порту `http://127.0.0.1:8000`.*

## 🧪 Запуск автотестов (CI/CD)

В проект интегрированы интеграционные тесты для проверки безопасности авторизации и блокировки пользователей. Робот в GitHub Actions автоматически прогоняет их при каждом Pull Request.

Для ручного запуска тестов локально выполните:
```bash
python manage.py test
```

## 🔗 Контракт взаимодействия (API Endpoints)
* `POST /api/auth/login/` — Авторизация (выдача токена).
* `GET /api/auth/me/` — Профиль текущего пользователя и его эффективные права.
* `GET /api/records/` — Чтение и создание защищаемых записей.
* `GET /api/admin/audit-logs/` — Журнал доступа с фильтрами (`?result=`, `?user_id=`, `?date_from=`).
* `GET /POST /api/admin/matrix/` — Чтение и сохранение интерактивной матрицы прав.
